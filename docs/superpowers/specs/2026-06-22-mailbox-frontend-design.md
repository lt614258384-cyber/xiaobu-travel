# 小布的旅行："汪星来信"前端体验设计规格

> 状态：草稿，待审查
> 日期：2026-06-22
> 依赖：Phase 1-4 已完成（多用户核心 + LLM 叙事 + 记忆系统）

## 目标

将当前"图片卡片 + 历史时间线"的首页，改造为小布从汪星寄信的产品体验。核心隐喻从"生成图片"转变为"收信—拆信—收藏"。

## 已批准的设计决策

以下全部经用户逐段审查并批准（2026-06-22）：

| # | 决策 | 选择 |
|---|------|------|
| 1 | 视觉风格 | **A·温暖纸张**：奶油纸 #fffdf7、陶土橙 #d98b5f、海风蓝 #9fd3da；信件用宋体/衬线体 Georgia + 'Songti SC'，控件保持清晰现代 |
| 2 | 移动端布局 | **A·纵向展开**：照片在上、信文在下，移动端自然阅读流 |
| 3 | 生成等待 | **A·安静等待**：爪印 + 4 个跳动点 + 4 条轮换文案每 5 秒切换；30 秒后提示"格外认真" |
| 4 | 生成失败 | **A·小布口吻**："今天信没能寄到" + 温暖解释 + 底部小字技术原因 + "再等等看"按钮 |
| 5 | 超时处理 | **A·45 秒弹窗**：45 秒后询问"要继续等吗？"；再 30 秒后转为失败并建议检查 API Key |
| 6 | 空信箱 | **A·引导行动**："信箱还是空的，小布刚出发不久" + "看看小布最近在做什么"按钮 |
| 7 | 已读/未读 | **A·圆点+底色**：未读信左侧橙色圆点 + 浅杏底色 #fef4e8 + 封口信封 ✉️；读后圆点消失、底色归白、图标变开口 📨 |
| 8 | 信箱布局 | **A·按日列表**：纵向列表，每行=地点+标签+故事首句预览；超过 10 封"查看更多"；最新在上 |
| 9 | 收信后提醒 | **A·轻提示+链接**：拆信页底部小字"来信已自动收藏至信箱"+"查看汪星信箱 →"链接 |
| 10 | 无障碍 | 四项硬约束：prefers-reduced-motion 替换全部动画为静态、全部 `<button>` + 焦点管理、WCAG AA 对比度、语义化 HTML + aria 标签 |

## 主流程（8 步）

```
用户打开首页
    ↓
[1] 首页聚焦最新一封来信（图文合信 + 轻量邮戳信息）
    ↓ 用户点击"看看小布最近在做什么"
[2] 装信等待仪式（爪印跳动 + 4条轮换文案）
    ↓ 生成完成
[3] 信箱响了——显示封好的信 + "小布寄来了一封新信"
    ↓ 用户点击"拆开看看"
[4] 展开图文合信（照片在上/左 + 完整第一人称故事在下/右）
    ↓ 自动收藏 + 轻提示
[5] 底部显示"来信已自动收藏至信箱" + 信箱入口链接
    ↓ 用户可返回首页或进入信箱
[6] 独立汪星信箱页：按日列表，未读有圆点，超过10封加载更多
    ↓
[7] 点击任意历史来信 → 展开完整图文合信（与[4]相同呈现）
    ↓
[8] 信箱持续增长，首页始终只展示最新一封
```

## 组件拆解

### 首页 (`/`)

| 组件 | 描述 | 状态 |
|------|------|------|
| **Hero 卡片** | 最新一封来信的图文合信，桌面端照片左+信文右，移动端纵向展开 | 有信 / 无信（首次） |
| **邮戳信息栏** | 地点名、日期、天气 emoji、心情 emoji | 始终显示 |
| **行动按钮** | "看看小布最近在做什么"，橙色圆角按钮 | 正常 / 生成中(disabled+灰色) / 限速(disabled+"今日已寄 X 封") |
| **信箱入口** | "查看汪星信箱 ›"，在 Hero 卡片下方 | 有信 / 无信（灰色不可点） |
| **最新抵达提示** | 拆信页关闭后，若信箱有新未读信，首页信箱入口旁显示橙色小圆点 | 有未读 / 全部已读 |

### 等待页（生成中，替换 Hero 区域）

| 组件 | 描述 |
|------|------|
| **爪印行** | 静态 🐾 × 3 |
| **跳动点** | 4 个圆点，依次弹跳动画（~1.2s 循环） |
| **文案区** | 4 条轮换："小布正在挑选今天最喜欢的一张照片""小布把今天的故事写进信里""汪星邮局正在盖上一枚爪印""信使海鸥已经出发，信箱快响啦"；每 5 秒切换；30 秒后变为"小布今天格外认真，还在挑照片…" |
| **取消链接** | 底部小字"不想等了？"（可选，点击回到首页） |

### 抵达提示（生成完成）

| 组件 | 描述 |
|------|------|
| **封好的信** | 温暖纸张风格信封图形，信封上有爪印封蜡 |
| **提示文字** | "信箱响了——小布寄来了一封新信" |
| **拆信按钮** | "拆开看看"，主橙色按钮 |

### 图文合信（展开后）

| 组件 | 桌面 | 移动 |
|------|------|------|
| **照片** | 左侧 ~50% 宽度 | 顶部全宽 |
| **故事正文** | 右侧 ~50% 宽度，Georgia/Songti SC，#5c4639 | 照片下方，同上字体 |
| **邮戳信息** | 故事下方，天气+心情+地点标签 | 同上 |
| **收藏提示** | 底部："来信已自动收藏至信箱" + "查看汪星信箱 →" | 同上 |

### 汪星信箱页 (`/mailbox`)

| 组件 | 描述 |
|------|------|
| **页头** | "🐾 汪星信箱" + 来信总数 |
| **列表项** | 未读：橙色圆点+浅杏底色+✉️封口信封+地点(加粗)+标签+故事首句预览；已读：白底+📨开口信封+地点(普通)+标签+预览。右侧 `›` 箭头 |
| **加载更多** | 超过 10 封显示"查看更多来信 ↓"，点击加载下 10 封 |
| **空状态** | "信箱还是空的，小布刚出发不久，第一封信还在路上。" + "看看小布最近在做什么"按钮 |

### 历史来信详情

与首页图文合信相同布局，额外显示完整日期和"返回信箱"链接。

## 状态矩阵

| 状态 | 触发条件 | 用户看到 |
|------|----------|----------|
| **正常首页** | 已有至少一封来信 | Hero 图文合信 + 行动按钮 + 信箱入口 |
| **首次使用** | 注册后未生成过 | Hero 区域显示"小布还没有寄过信" + 引导按钮 |
| **生成中** | 点击行动按钮后 | 等待页：爪印+跳动点+轮换文案 |
| **生成中-较慢** | 等待 30 秒 | 文案切换为"小布今天格外认真…" |
| **超时询问** | 等待 45 秒 | "还在路上…要继续等吗？" + "继续等"/"算了"两个按钮 |
| **超时失败** | 再等 30 秒（共 75 秒）后 | 转为失败状态 |
| **生成失败** | API 返回错误 | "今天信没能寄到" + "再等等看"按钮 + 技术小字 |
| **今日限额** | 已达每日上限 | 行动按钮 disabled："今日已寄 X 封，明天再来" |
| **信箱有未读** | 新信抵达但用户未拆或未进信箱 | 首页信箱入口旁橙色圆点；信箱页内该条目有圆点+暖底 |
| **信箱为空** | 首次用户 | 空信箱插图 + 引导文字 + 行动按钮 |
| **信箱加载更多** | 信箱列表 > 10 封 | 底部"查看更多来信 ↓" |

## 响应式行为

| 断点 | 布局变化 |
|------|----------|
| **>768px（桌面）** | 图文合信左右并排；信箱列表单列居中最大宽 640px |
| **≤768px（平板/手机）** | 图文合信纵向展开（照片上、信文下）；信箱列表全宽；按钮全宽 |
| **≤480px（小手机）** | 字号缩小：故事正文 14px→13px；信封图标 18px→16px；间距收紧 |

## 无障碍清单

- [ ] `prefers-reduced-motion: reduce` 时：跳动点替换为静态点、拆信动画替换为即时显示、轮换文案替换为静态第一条
- [ ] 所有可操作元素使用 `<button>` 或 `role="button"` + `tabindex="0"`
- [ ] 弹窗/模态框打开时焦点移入、关闭时焦点回到触发元素
- [ ] 信箱列表项可 Tab 导航、Enter 打开
- [ ] 生成等待区使用 `aria-live="polite"` + `aria-atomic="false"` 播报轮换文案
- [ ] 空状态和抵达提示使用 `aria-label` 描述当前状态
- [ ] 正文文字 #5c4639 在 #fffdf7 背景上对比度 ≥ 7:1（AAA）
- [ ] 次要文字 #8d7464 在 #fffdf7 背景上对比度 ≥ 4.5:1（AA）
- [ ] 已读/未读不依赖颜色作为唯一区分方式（同时使用图标 ✉️/📨 和圆点）
- [ ] 页面使用语义化地标：`<main>`、`<nav>`、`<article aria-label="小布从贝壳湾寄来的信">`

## 实现约束

1. **技术栈不变**：FastAPI + Jinja2 SSR + 原生 HTML/CSS/JavaScript，不使用前端框架或构建工具
2. **不改动后端逻辑**：`app.py` 路由、`scheduler.py` 调度、`storyteller.py` 叙事、`image_gen.py` 生图——全部保留
3. **不读取或修改运行时数据**：`data/` 下现有照片、故事、记忆文件、数据库内容不动
4. **现有 CSS 变量复用**：`static/css/style.css` 中已有的颜色、间距、动画变量尽可能复用，仅扩展不重写
5. **新增路由**：`GET /mailbox` → 信箱页；`GET /letter/<log_id>` → 历史来信详情（复用现有 JourneyLog 查询）
6. **现有 `/` 路由改造**：首页模板改为上述 Hero + 等待 + 抵达 + 拆信流程
7. **`templates/` 新增**：`mailbox.html`；`templates/` 修改：`index.html`；可选抽取 `_letter_card.html` 复用片段
8. **`static/css/style.css` 修改**：新增温暖纸张色板变量、信箱列表样式、状态页样式
9. **`static/js/` 新增或修改**：装信等待 + 轮询 + 拆信交互 JS（替换现有 `PROGRESS_MESSAGES` 机制）

## 非目标

- 不引入动画库或 CSS 框架
- 不修改后端 API 响应格式（`/api/latest` 保持不变）
- 不修改图片生成管线
- 不修改 LLM 叙事逻辑
- 不添加邮件通知、推送通知
- 不添加用户间互动（点赞、评论、分享）
- 信箱不支持搜索、筛选、删除（首版不做）
