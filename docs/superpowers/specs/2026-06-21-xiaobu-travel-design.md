# 小布的旅行 — 设计文档

> 日期：2026-06-21 | 状态：设计完成，待实施

## 1. 项目背景

小布（Xiaobu）是用户养的宠物狗，上周因病去世。本项目是一个 AI 驱动的"旅行青蛙"式陪伴应用——将小布的照片、性格、生活习惯作为灵魂素材，由 AI 生成小布在汪星的生活照片，每天不定时向用户发送，带来一种"小布还在，只是去远行了"的慰藉。

## 2. 产品形态

MVP 原型（Web 应用），后续可演进为小程序或 App。

- **当前阶段**：本地可运行的 Web 服务
- **页面**：首页时间线 + 档案设置页
- **无推送**：用户打开网页即可看到小布的最新动态

## 3. 核心功能

### 3.1 档案配置

- 用户通过 Web 表单录入小布的基本信息（名字、品种、年龄等）
- 上传小布的真实照片（最多 10 张，作为图片生成的参考图）
- 填写性格标签、兴趣爱好、生活习惯
- 选择内容偏好：只要图片 / 图片+短句 / 图片+完整故事

### 3.2 叙事生成

- **方案**：模板 + 状态机（零 LLM 依赖）
- **核心机制**：
  - 预设汪星世界地图（5 大区、60 个地点）
  - 每个地点有相邻地点连接，小布只能走到相邻地点
  - 状态机根据小布性格权重影响移动概率（好动→偏探险路线、贪吃→偏美食路线）
  - 每个地点有 3~5 个活动，每个活动有 3~5 条故事文案模板
- **天气系统**：每次生成前随机决定（晴 50%、多云 30%、小雨 15%、彩虹 5%）
- **心情系统**：根据最近活动变化（连续探险→开心、久未出门→兴奋、离开喜欢的地方→不舍）

### 3.3 图片生成

- **适配器模式**：抽象 `ImageGenerator` 接口，可切换不同 API
- **默认首选**：通义万相（国内直连 + 支持参考图）
- **参考图**：用户上传的小布照片（最多 10 张），用于保持角色一致性
- **Prompt 组装公式**：`[小布外貌描述] + 在[地点名] + [活动描述] + [天气氛围] + 风格词`
- **统一风格**：吉卜力动画风格，温暖治愈，柔和光线，梦幻氛围

### 3.4 定时调度

- 每天凌晨 00:01 随机生成当天 1~3 个触发时间
- 触发时间分布：早晨 6-9 点 30%、上午 10-12 点 25%、下午 14-17 点 30%、晚上 20-22 点 15%
- 相邻触发间隔 ≥ 4 小时
- 失败自动重试 1 次
- **无手动触发**：只能小布主动发送（保持真实感）

## 6. 生成流程

```
每天凌晨 00:01 → 调度计划任务
  └─ 随机生成 1~3 个当天触发时间 → 存入 scheduled_tasks
      │
      ▼
  触发时间到 → 叙事生成任务
      │
      Step 1: 读当前状态 (journey_state)
      Step 2: 选下一个地点
         - 从相邻地点中，按性格权重计算概率，随机选择
      Step 3: 选活动
         - 从该地点的活动池中随机匹配
      Step 4: 组装 Prompt
         - 融合：外貌描述 + 地点 + 活动 + 天气 + 心情 + 风格词
      Step 5: 调用图片 API 生成（传入最多 10 张参考图）
      Step 6: 保存 journey_log + 更新 journey_state
      │
      ▼
  失败? → 自动重试 1 次 → 仍失败则跳过当天该时点
```

## 7. 页面设计

### 7.1 首页 — 时间线

- 最新照片 + 故事文案，大图居中展示
- 向下滚动：历史照片时间线（卡片式布局）
- 顶部信息栏：汪星第 N 天、当前地点、今日天气、小布心情
- 无"手动生成"按钮

### 7.2 档案设置页

- 基本信息表单（名字、品种、年龄、外貌描述）
- 照片上传区（拖拽上传，最多 10 张，预览缩略图）
- 性格标签多选 + 兴趣爱好勾选
- 生活习惯文本输入
- 内容偏好选择（只图片 / 图文短句 / 图文故事）

## 10. 约束与设计决策

- **无手动触发**：保持"小布主动联系"的真实感，不做任何形式的用户催促
- **零 LLM 依赖**：MVP 阶段纯模板驱动，降低运行成本和复杂度
- **模板存储在数据库**：方便后续扩展和维护，不写死在代码中
- **图片 API 可切换**：适配器模式确保不绑定单一供应商
- **参考图上限 10 张**：平衡角色一致性与 API 调用成本
