# 小布的旅行 🐾

> 一只金毛犬的汪星旅行日记 —— AI 驱动的宠物陪伴应用

---

小布是我养的金毛犬。它离开后，我一直在想：如果有一个地方，能让我每天看到它在做什么、去了哪里、交了哪些朋友，该有多好。

这就是"小布的旅行"——一个 AI 驱动的陪伴应用。小布在**汪星**继续它的冒险：每天去不同的地方（彩虹桥、贝壳湾、灯塔礁、彩色小镇……），做各种有趣的事（赶海、挖沙堡、写明信片、钓鱼、学画画……）。AI 为它**生成一张照片**，DeepSeek V4 Pro 为它**写一段旅行日记**。照片是半写实手绘水彩插画风，故事是用狗狗的感官写的第一人称叙事——闻到什么、听到什么、爪子踩到什么、尾巴怎么摇。

最打动我的是一条来自彩色小镇的故事：

> *"阳光暖烘烘地洒在背上，我踩着彩色房屋前的石板路，尾巴摇得像小旗子。街道上飘着烤小鱼干的香味，混着隔壁萨摩耶姐姐刚晒好的蒲公英草垫味道……明信片塞进邮筒时，尾巴尖扫过铁皮，发出'哐当'一声，像灯塔的钟在轻轻回应。风里好像有家里沙发上的阳光味，暖暖的，和这里的一样。"*

## 功能

- 🐕 **多用户注册**：每个人养自己的小布，互不干扰
- 📋 **宠物档案**：上传照片、填写外貌、性格、兴趣爱好，以及真实的回忆
- 🤖 **AI 视觉分析**：首次上传照片后，Doubao Vision 自动提取狗的详细外貌特征
- 🎨 **AI 图片生成**：Seedream 4.5 图生图，保持狗的品种/毛色/五官不变，只换场景
- ✍️ **LLM 故事生成**：DeepSeek V4 Pro 基于全部历史记忆，写第一人称旅行日记——有呼吸感、有连续性、有真实的狗狗感官
- ⏰ **每日定时生成**：每天随机规划 1-3 张，像真的在上路
- 📮 **手动生成**：点击按钮，8 步明信片寄送动画，新照片自动出现
- 📝 **记忆系统**：所有故事累积成记忆文件，LLM 引用过往经历保持叙事连贯
- 🌍 **60 个地点 × 203 种活动**：状态机驱动的汪星世界观

## 技术原理

```
浏览器 (纯HTML/CSS/JS SSR) 
    ↓
FastAPI + Jinja2
    ↓
┌──────────────┬──────────────┬─────────────────┐
│ 状态机叙事    │ 图片生成      │ 故事生成          │
│ 60地点+203活动 │ Seedream 4.5 │ DeepSeek V4 Pro  │
│ 天气/心情/选择 │ 图生图模式    │ 1M上下文全量记忆   │
└──────────────┴──────────────┴─────────────────┘
    ↓
SQLite + APScheduler
```

- **叙事**：状态机从当前位置的相邻地点中加权选择（性格影响权重）
- **生图**：参考照片 base64 编码传入，Prompt 要求"保持狗的特征完全不变，只改变背景"
- **故事**：全量记忆文件（性格+外貌+全部旅程+真实回忆）喂给 DeepSeek V4 Pro，每次写 100-200 字第一人称日记
- **安全**：Argon2id 密码哈希、Cookie Session + CSRF 双提交、限速、审计日志、生产安全自检

## 技术栈

Python 3.13 · FastAPI · SQLAlchemy · APScheduler · Jinja2 · SQLite · 火山引擎 Seedream 4.5 · DeepSeek V4 Pro · 纯前端无框架

## 快速开始

```bash
git clone https://github.com/lt614258384-cyber/xiaobu-travel.git
cd xiaobu-travel
pip install -r requirements.txt
DATABASE_URL="sqlite:///xiaobu.db" IMAGE_API_TYPE="fake" python run.py
# 打开 http://localhost:8000
```

首次使用：`python manage.py init-owner --email <邮箱> --password <密码>`
