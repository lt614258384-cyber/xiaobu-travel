2. 无障碍要求（项目日志已约束，确认即绑定到规格）

🎬 prefers-reduced-motion

当用户在操作系统设置了"减少动效"，所有动画（爪印跳动、信封折叠、轮换文案淡入淡出）替换为静态状态显示。

✅ 加载时直接显示静态"小布正在写信…"不含动画
✅ 拆信动画替换为即时显示完整内容
❌ 不使用自动播放的 CSS animation/transition

⌨️ 键盘可访问性

所有交互（首页按钮、拆信按钮、信箱列表、弹窗关闭）必须通过键盘完成。

✅ 所有可点击元素使用 <button> 或 role="button" + tabindex
✅ 弹窗打开时焦点移入，关闭时焦点回到触发元素
✅ 列表项可用 Tab 导航、Enter 打开
❌ 不使用 div onclick 替代 button

🎨 色彩对比度

温暖纸张色板需通过 WCAG AA 对比度最低要求。

✅ 正文文字 #5c4639 在 #fffdf7 背景上 → 对比度约 7.4:1（通过 AAA）
✅ 次要文字 #8d7464 → 对比度约 4.8:1（通过 AA）
❌ 不依赖颜色作为唯一信息传达方式（已读/未读同时用图标和圆点）

🔍 语义化与屏幕阅读器

有意义的内容结构和 aria 标签。

✅ 页面使用语义化地标：<main>、<nav>、<article>
✅ 信件内容用 <article aria-label="小布从贝壳湾寄来的信">
✅ 加载状态用 aria-live="polite" 播报文案变化
✅ 空信箱用 aria-label 描述当前状态
